Указать не менее 10 базовых команд Git и краткое описание.
1.git clone — копирует существующий удаленный репозиторий на ваш компьютер вместе со всей историей изменений
2.git status — показывает текущее состояние рабочего каталога: какие файлы изменены, добавлены в индекс или не отслеживаются
3.git add — добавляет измененные файлы в зону подготовки (индекс), подготавливая их к сохранению
4.git commit — создает снимок (сохранение) подготовленных файлов с текстовым описанием внесенных изменений
5.git push — отправляет ваши локальные коммиты в удаленный репозиторий (например, на GitHub)
6.git init — создает новый пустой локальный репозиторий в текущей папке
7.git pull — скачивает изменения из удаленного репозитория и сразу объединяет их с вашей текущей веткой
8.git branch — показывает список веток, а также позволяет создавать новые ветки или удалять их
9.git checkout (или git switch) — переключает вас между разными ветками или позволяет вернуться к старой версии файла 
10.git log — выводит историю всех коммитов с указанием авторов, дат и уникальных идентификаторов
